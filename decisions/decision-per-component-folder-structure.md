# `packages/design-system/src` moves to one folder per component, matching Blade's real structure

- Status: accepted
- Date: 2026-08-22
- Context: Phase 5 (Primitives), raised while reviewing the `atomicConfig.mjs`/`generatedValidSteps.mjs` files added earlier the same day

## Context

`packages/design-system/src` had grown to nine files sitting flat at the top level: `Box.tsx`, `Stack.tsx`, `Inline.tsx`, `Container.tsx`, `atomicConfig.mjs`, `atomicConfig.d.mts`, `generatedValidSteps.mjs`, `generatedValidSteps.d.mts`, `global.d.ts`, plus `index.tsx`. Fine at four components; flagged as a real forward-looking problem before it compounds — the roadmap already commits to Text, Heading, Icon, VisuallyHidden (Phase 5), then Button, Input, Dialog, Menu and more (Phase 7+), each of which will eventually want its own tests and Storybook stories alongside its implementation. A flat folder with 100+ components' worth of `.tsx`/`.test.tsx`/`.stories.tsx` files all as siblings doesn't scale, and the cost of fixing it only grows with every component added on top of the wrong shape.

## Decision

Moved to one folder per component under `src/components/`, each folder owning everything specific to that component:

```
src/
  components/
    Box/
      Box.tsx
      atomicConfig.mjs
      atomicConfig.d.mts
      generatedValidSteps.mjs        (gitignored, regenerated by scripts/generate-atomic-css.mjs)
      generatedValidSteps.d.mts
    Stack/
      Stack.tsx
    Inline/
      Inline.tsx
    Container/
      Container.tsx
  index.tsx      (top-level barrel export)
  global.d.ts    (top-level — genuinely package-wide ambient typing, not one component's concern)
```

Not an invented convention — matches Blade's own real, already-confirmed structure from the earlier evidence-first research pass: `packages/blade/src/components/Box/BaseBox/baseBoxStyles.ts`, `.../BaseBox/types/propsTypes.ts`, `.../Box/styledProps/useStyledProps.ts`, `.../Box/__tests__/baseBoxStyles.test.ts` — one folder per component, with that component's internals (styling resolver, prop types, tests) nested inside rather than sitting loose at the top of `src/`.

`atomicConfig.mjs`/`atomicConfig.d.mts`/`generatedValidSteps.*` moved into `Box/` specifically, not to a new top-level `src/styling/` or similar — they're Box's own config (see the earlier explanation of why this file exists: it exists to keep `Box.tsx` and `scripts/generate-atomic-css.mjs` from drifting apart on Box's own prop surface, nothing else). If a future primitive needs entirely new style props of its own that the atomic-CSS system doesn't yet know about, those get added to this same file, in this same folder — not a second, parallel `atomicConfig.mjs` for that component. Matches how Blade nests `styledProps/` under `Box/` rather than at the top of `src/`, for the same reason: it's conceptually Box's own mechanism that other things borrow, not a package-wide concern.

Future test files use a `__tests__/` subfolder per component (`Box/__tests__/Box.test.tsx`), matching Blade's confirmed pattern exactly, rather than a colocated sibling file (`Box.test.tsx`) — decided explicitly, not defaulted.

## Consequences

- `scripts/generate-atomic-css.mjs` updated to import from `../src/components/Box/atomicConfig.mjs` and write `../src/components/Box/generatedValidSteps.mjs` (was `../src/atomicConfig.mjs` / `../src/generatedValidSteps.mjs`).
- `Stack.tsx`, `Inline.tsx`, `Container.tsx` updated to import `Box` from `../Box/Box` (was `./Box`, a same-folder sibling).
- `index.tsx` (the top-level barrel export) updated to import from `./components/Box/Box`, `./components/Stack/Stack`, etc.
- `.gitignore`'s entry for the generated valid-steps file updated to the new path.
- Nothing outside this package needed to change — `apps/playground` and everything else consumes `@farmsapp/design-system`'s compiled public export, never these internal source paths, so the restructure is invisible to every consumer.
- Re-verified: full fresh `turbo run build lint typecheck --force` (19/19), and a real browser check (`playwright-core`/Edge) against the rebuilt playground confirmed identical output to before the move — swatch dimensions, `margin=auto` centering, inverse-swatch color, root max-width centering all unchanged.
- Done now, deliberately, while only 4 components exist and none of this had been committed yet — the cheapest point this restructure will ever be. Every component built from here forward (starting with Text/Heading, Phase 5 Chunk 04) goes directly into the right shape instead of needing to be moved later.
